# Паспорта: настройки проверки

Два уровня, оба в `_claude` (видны коллегам, версионируются вместе с проектом):

* **Паспорт проекта** — `<проект>\_claude\project.yaml`: общее для всех разделов объекта (маска шифра, словари,
  группа Telegram по умолчанию, печать, оформление выдачи).
* **Паспорт раздела** — `<раздел>\_claude\section.yaml`: сооружения раздела, шаблон ведомости, где номер листа,
  штамп, ОД, исключения. Всё, чего нет в разделе, берётся из проекта.

Группы Telegram не вписываются руками: `/bind <раздел|проект>` в группе — бот сам пишет её ID в нужный паспорт.

## Поля паспорта проекта

| Поле | Смысл |
|---|---|
| `проект` | Название для уведомлений |
| `шифр_маска` | Шаблон шифра, `{n}` — номер ИЗ. Буква B — латинская |
| `telegram.группы` / `telegram.управление` | ID групп (через `/bind`); белый список Telegram ID для правок |
| `сооружения_коды` | Регулярное выражение кодов сооружений (для C1 «чужой код») |
| `нормативы_замены`, `термины_замены` | Словари для C2/C3: «неверно → верно» (регулярные выражения) |
| `печать.*` | Плоттер, добавлять ли недостающие форматы |
| `выдача.*` | Шаблон имени папки версии, подпапки, имена PDF и сводного PDF |

## Поля паспорта раздела

| Поле | Смысл |
|---|---|
| `раздел` | Название |
| `сооружения` | Код → ИЗ, трасса/доп. параметры, папка |
| `штамп` | Файл внешней ссылки штампа, шаблон наименования (handle-ы — для правки F1) |
| `номер_листа` | Где номер: атрибут (блок/тег, часто поле от имени файла) и/или текст в графе «Лист» |
| `ведомость_листов` | Шаблон наименований листов (`{код}` подставляется) — для S1, имён PDF, ведомости ОД |
| `исключения` | Отличия конкретного сооружения (другой состав листов, доп. листы без номера) |
| `ОД` | Образец, генератор, `согласование: группа` |
| `проверки.включены`, `предупреждения_блокируют` | Набор проверок; 🟡 требует подтверждения выпуска |

Полные примеры — `..\examples\project.yaml`, `..\examples\section_culverts.yaml`.
