Общая папка объекта, с ней работают несколько проектировщиков. Отвечать по-русски.

## Инструменты
Работа с DWG/PDF комплектов — через плагин Claude Code **rd-ci** (навыки `autocad-rd`, `check-set`).
Пакет называется **autocad-rd**, внутреннее имя Claude-плагина **rd-ci** сохранено для совместимости.
Если навыков нет в сессии — сказать пользователю, что пакет не установлен: https://github.com/yegori/agent-skill-autocad-rd/blob/master/docs/INSTALL.md.
Без плагина DWG не трогать.

## Объект
- Наименование, заказчик, организация, стадии.
- Где ПД (шифр ПД), где РД, где исходные данные и отправленное.
- Шифр РД: шаблон, латиница/кириллица, документы изделий.
- Структура папки выдачи (имена подпапок, папка внешних ссылок), как называются файлы листов, где штамп.
- Исполнители в штампах, экспертиза.

## Решения, действующие для всего объекта
- Принятые формулировки, нормативы, марки — то, что одинаково во всех разделах.
- Инженерные значения меняет только автор раздела; Claude предлагает «было → стало».
