# rd-ci — инструкции для Claude

Сервис «CI для РД» (проверка и сборка комплектов рабочей документации AutoCAD) и его инструменты. Пользователь — инженер-проектировщик,
пишет по-русски; отвечать по-русски.

## Плагин
Репозиторий — плагин Claude Code `rd-ci` и marketplace `rd-ci-arkhyz` (`.claude-plugin/`), навыки в `skills/`. Коллеги ставят его по `docs/INSTALL.md`;
после push изменения доходят до них автоматически. Перед коммитом — `claude plugin validate .`; пути не ломать: в навыках `${CLAUDE_PLUGIN_ROOT}`,
в скриптах `$PSScriptRoot` / `$WorkRoot`; в папку плагина ничего не писать — у коллег это кэш.

## Правила пользователя
- Массовые правки DWG: сначала один (самый большой) файл → показать результат в PDF → «ок» → весь пакет.
- Работать на копиях в `%LOCALAPPDATA%\Temp\acc\…`; исходник заменять только с проверенной резервной копией; файлы, открытые у пользователя, не трогать.
- AutoCAD пользователя не автоматизировать и чужие процессы acad.exe не завершать; свой acad.exe / accoreconsole — по одному, никогда одновременно.
- Объекты СПДС не взрывать — править через API (`toolkit/spds_text`).
- Инженерные значения не менять без согласия — предлагать с обоснованием. Вопросы — с вариантами, рекомендуемый первым.
- Существующие папки выдач не перезаписывать; новая выдача — новая папка `<дата> - <шифр>\DWG` + `\PDF`.
- Решения — в `docs/06_decisions.md`, нерешённое — в `docs/07_open_questions.md`, общие находки — в `docs/11_pitfalls.md`; изменения коммитить
  (в конце сообщения `Co-Authored-By`). Проектная специфика — в `_claude` проекта, не сюда.

## Техника
- `.ps1` — из PowerShell 7 (`pwsh`), не из Git Bash. Python — `python -I`; в pwsh перед ним `[Console]::OutputEncoding = [Text.Encoding]::UTF8`.
- Тексты с `\` (пути Windows) писать через Write/Edit или raw-строки Python: `\a`, `\b`, `\20…` в обычной строке портят файл.
- Переменные PowerShell не различаются регистром (`$C` = `$c`).
- Окружение: AutoCAD 2024 + Civil 3D OE, СПДС GraphiCS 2023 x64, Python 3 (pymupdf, ezdxf, numpy, scipy, shapely, Pillow, openpyxl).
