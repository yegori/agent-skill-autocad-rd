вынесены общие инструменты `toolkit\`, и материал для `docs\12_arkhyz_test_cases.md`.

| Папка | Откуда | Что ценно |
|---|---|---|
| `водопропуски\` | `Водопропуски\_claude\` | `README.md` — решения пользователя по ОД, найденные/исправленные ошибки; `скрипты\gen_od.py` + `run_od.ps1` — генератор ОД (ведомости LINE+TEXT, скрытые работы, ссылочные) → обобщён в `toolkit\od\`; `dump_texts.py` — тексты из DXF |
| `водопропуски\<сооружение>\` | `<сооружение>\_claude\*.md` | контекст ОД по каждому сооружению: принятые значения, откуда взяты (профиль/колодец/КВ-1), открытые вопросы |
| `дренаж\` | `площадной дренаж\_claude\` | `README.md`; `gen_od_pd.py`/`run_od_pd.ps1` — ОД дренажа; `renum_pdf_pd.ps1` → `toolkit\renum_stamp.ps1`; `plot_pd.ps1` → `toolkit\plot_set.ps1`; `kamenfix\` — первая версия плагина СПДС → `toolkit\spds_text\` |
| `В-5А-1\` | `Водопропуски\В-5А-1\_claude\` | ручная проверка объёмов (категория Q): `КОНТЕКСТ_ПРОВЕРКИ.md` — все находки и методика; `скрипты\analyze_00{5,6,7}_*.py`, `massprop_006.ps1` → `toolkit\quantities\`; `build_xlsx.py` — сводная Excel (данные спецификаций зашиты в скрипт); `отчеты\*.xlsx` — образец результата |

Не скопированы: рендеры PDF и результаты MASSPROP (`рендеры_PDF\`, `результаты_DWG\`), собранная dll, служебные копии PMP.
