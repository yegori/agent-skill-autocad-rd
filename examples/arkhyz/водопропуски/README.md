### Чем ГСИ-колодцы отличаются от В-5А-1 (почему текст переписан)

В-5А-1 — монолитный ж/б колодец Км-1 (бетон В30, А500С, шнур, «Славянка», Zinga, плиты ПНД, ЗД-1). Все остальные — колодец К-1 из ГСИ:
уровень 1 — ГСИ-М-6×2×0,5, уровни 2…n — ГСИ-К-1,5×1×1, подготовка щебень 400 мм + бентомат АСЛ 50 + геотекстиль 200; противофильтрационный экран из ЦПС; труба СВМГТ с бандажами; цементно-песчаная перемычка; грунтовая обойма; КВ-1 — 1-й ряд ГСИ-М 0,5 на анкерах А-1, 2-й ряд — рёбра ГСИ-М-3×2×0,17. Поэтому в ОД заменены п.2, п.5, нормы п.6, скрытые работы, ссылочные документы.

### Как собрать ОД (скрипты в `скрипты\`)

1. Добавить запись в словарь `S` в `gen_od.py` (ключ = номер, например `'54'`) и, если нужно, строку в `$map` в `run_od.ps1`.
2. Из PowerShell: `.\скрипты\run_od.ps1 -Keys 54` → проверочная печать `C:\Users\yegori\AppData\Local\Temp\acc\gen\w54\check.pdf`. Посмотреть.
3. `.\скрипты\run_od.ps1 -Keys 54 -Deploy` → папка выдачи с ОД, штампом, обложкой (.doc + PDF), проверочная печать в `<сооружение>\_claude`.
4. Остальные DWG из последней выдачи + `Внешние_ссылки\Трассы.dwg`, `съемка 500 этап 1.dwg` скопировать в `DWG` (кроме `_recover`, не перезаписывая `001 ОД.dwg` и `штамп.dwg`).

`dump_texts.py <файл.dxf>` — все тексты/атрибуты по макетам и модели (для поиска заголовков, отметок, ошибок «чужого» сооружения).

### Техника (что выяснилось)

- **accoreconsole** запускать только из PowerShell (Git Bash портит `/i`, `/s`); DWG копировать в `C:\Users\yegori\AppData\Local\Temp\acc\…` под латинскими именами; LISP писать прямо в `.scr` (SECURELOAD не грузит `.lsp`). `.scr` с кириллицей — **cp1251**.
- Правка MTEXT: `entget` → убрать группы 1 и 3 → добавить куски по ≤200 символов (группы 3, последний — 1) → `entmod`. Каждый кусок — отдельной строкой `.scr`: длинная строка ломает ввод консоли.
- В DXF `^I` — это символ табуляции; в LISP писать `\t`, иначе в тексте печатается «^I». Знаки, которых нет в cp1251 (∅), — MTEXT-кодом `\U+2205`.
- Ведомости в ОД изначально были таблицами **СПДС GraphiCS** (прокси, в консоли не редактируются). Пользователь их взорвал; теперь это LINE + TEXT на слое `КЖ-текст`, стиль «ГОСТ 2.304», h 2,5 (заголовки 3,5), наклон 15°, сетка X 4538.15 / 4553.15 / 4693.15 / 4723.15 (ссылочные — 4604.33), строки 8 / 11,35 (3 строки текста). `gen_od.py` удаляет их и строит заново.
- Шифр и наименование в штампе — во внешней ссылке `Внешние_ссылки\штамп.dwg` (общая для всех листов папки): MTEXT handle `15B` — шифр, `157` — «Водоотведение. \P Горнолыжная трасса … \P Водопропускное сооружение …».
- Печать листа: `(setvar "CTAB" "ОД") (command "_.-PLOT" "_N" "" "" "DWG To PDF.pc3" "<pdf>" "_N" "_Y")` — на копии DWG, рядом должны лежать `Внешние_ссылки`.
- Обложка .doc — правка через Word COM (Find/Replace), PDF — `ExportAsFixedFormat(…, 17)`. Заменять фразы целиком («ГОРНОЛЫЖНАЯ ТРАССА T5A»), т.к. «T5A» есть и в названии проекта.
- Текст PDF листов — SHX, не извлекается; читать рендером (pymupdf) с кропом. При чтении кропов учитывать, что картинка показывается уменьшенной (масштаб в подписи изображения).
