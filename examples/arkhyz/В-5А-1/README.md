## Как повторить проверку для новой выдачи

Нужно: AutoCAD 2024 (accoreconsole), Python с пакетами `pymupdf openpyxl ezdxf numpy scipy shapely pywin32`.

1. **PDF → картинки** (текст в PDF — SHX, не извлекается):
   `python скрипты/render_pdf.py "<выдача>\pdf" <папка_png>`
2. **DWG → DXF** (из PowerShell, не из Git Bash):
   `.\скрипты\export_dxf.ps1 -Src "<выдача>\dwg"` → DXF в `C:\Users\yegori\AppData\Local\Temp\acc`
3. **Объёмы 3D-тел ГСИ (лист 006):** `.\скрипты\massprop_006.ps1`
4. **Анализ:**
   - `python скрипты/analyze_007_slopes.py d007.dxf` — площади защиты откосов в плане и по 3D-откосу котлована;
   - `python скрипты/analyze_006_gsi.py d006.dxf <папка mp>` — рёбра ряда 3, контуры ряда 1, объёмы тел рядов 1–2;
   - `python скрипты/analyze_005_kolodets.py d005.dxf` — габариты бетона колодца.
5. **Сводная Excel:** `python скрипты/build_xlsx.py "<путь>.xlsx"`. Данные спецификаций и замечания заданы в самом скрипте — при новой выдаче их надо обновить. После сборки открыть файл в Excel для пересчёта формул.

## Технические особенности

- accoreconsole из Git Bash не работает: MSYS превращает `/i`, `/s` в пути. Запускать из PowerShell.
- AutoCAD не грузит `.lsp` из непроверенных папок (SECURELOAD) — LISP-код пишется прямо в `.scr`.
- Длинные пути и кириллица мешают консоли — DWG копируются в `C:\Users\yegori\AppData\Local\Temp\acc` под именами `d005.dwg` и т.п.
- ezdxf не читает 3D-тела этого DWG (формат SAB) — объёмы берутся через MASSPROP.
- Слои модели: `inf_anti_errosion` — противоэрозия; `!габион` — ГСИ на откосе (л.007) / прочие габионы (л.006); `inf_gsi_apron_mat` — КВ-1 ряд 1; `inf_gsi_ditch_wall` — ряд 2; `inf_gsi_ditch_rib` — ряд 3 (рёбра); блок `Котлован_В-5А-1` — 3D-линии откосов котлована.
