### kamenfix — правка текста внутри объектов СПДС GraphiCS

- Таблицы спецификаций — `mcsDbObjectTable2` (API: `Multicad.Symbols.Tables.McTable`, ячейка `t[r,c].Value`), многослойная выноска на разрезе — `mcsDbObjectNoteMultilayer` (`McNoteMultilayer.Units[i].Text`, заменять элемент новым `McNoteUnit`), позиционные выноски — `McNotePosition.FirstLine/SecondLine`. Доступ: `McObjectManager.GetObject(McObjectId.FromOldIdPtr(acadId.OldIdPtr))`; перед правкой `ent.TryModify()`, после — `ent.DbEntity.Update()`. Плагин также правит TEXT/MTEXT/атрибуты и рефлексией — строковые свойства прочих mcs-объектов.
- Файлы: `KamenFix.cs` (команда KAMENFIX), `build_kamen.ps1` (csc .NET Fw 4, ссылки acmgd/acdbmgd/accoremgd + `mapimgd.dll`, `mapibasetypes.dll` из `C:\Program Files\CSoft\СПДС GraphiCS 2023 x64\mg142x64`), `bin\KamenFix.dll`, `run_kamen.ps1 -In a.dwg,b.dwg -Out a_fix.dwg,b_fix.dwg -Log x.log [-Dry]`, `refl_spds.ps1` (просмотр классов API; запускать `powershell.exe` 5.1).
- `run_kamen.ps1` стартует **отдельный** `acad.exe /nologo /b` без чертежа (AutoCAD пользователя не трогается), NETLOAD (SECURELOAD временно 0), KAMENFIX сам открывает файлы из `KAMEN_IN`, PROXYNOTICE временно 0, SaveAs в `KAMEN_OUT`, журнал `HIT/SEEN/UPDATED/SAVED/DONE/ALLDONE`; после ALLDONE процесс убивается. `-Dry` — только поиск.
- 14.10: 8 спецификаций + 3 выноски исправлены; «120» в отметках/координатах — SEEN, не тронуты. 15 файлов ≈ 10 мин.

## Техника и грабли

- **accoreconsole** — только из PowerShell; `.scr` с кириллицей — cp1251; длинные строки MTEXT — кусками ≤200 (см. `set_mtext` в gen_od_pd.py). Файлы дренажа — Civil 3D (грузятся модули AECC, ~15 с на открытие).
- В консоли **нет** `layoutlist` и ActiveX (`vlax-get-acad-object` → nil): макеты брать из `(dictsearch (namedobjdict) "ACAD_LAYOUT")` — имя = группа 3 перед 350 (в самом объекте Layout первая группа 1 — имя набора печати, пустое!), порядок вкладок — группа 71 объекта.
- Выход: `(command "_.QUIT" "_N")` — иначе зависает на «Сохранить изменения?». Перед запуском проверять баланс скобок LISP (зависание «(_>»).
- Объекты СПДС в консоли — `ACAD_PROXY_ENTITY`, не правятся; `arxload mcsenabler.dbx` в консоли не работает → нужен полный acad.exe + плагин.
- **Не запускать acad.exe и accoreconsole одновременно** — 14.10 так упал acad.exe (Access Violation, `служебное\acad.err_падение_15.18.txt`).
- Полный acad.exe в пакетном режиме: окно «Информация о прокси-объектах» блокирует → PROXYNOTICE=0 на время; `QSAVE/QUIT` в `/b`-скрипте могут повиснуть на диалоге → сохранять из плагина `db.SaveAs`, процесс завершать по журналу.
- Печать: `(command "_.-PLOT" "_N" "" "" "DWG To PDF.pc3" "<pdf>" "_N" "_Y")` по текущему CTAB. Лист 10 ИЗ16 (котлован 4А-3) — формат «UserDefinedMetric (1189.00 x 420.00мм)»; его не было в `%APPDATA%\Autodesk\AutoCAD 2024\R24.3\rus\Plotters\PMP Files\DWG To PDF.pmp` → добавлен 14.10 (копии до/после — `служебное\`). Признак в логе: «Нет подходящего носителя».
- Текст в PDF листов — SHX, не извлекается: проверять рендером (pymupdf) кропов; на листах А0 штамп не в углу страницы (страница повернута).
- `.dwl` в папках выдачи — часто старые; занятость проверять открытием файла на запись.
